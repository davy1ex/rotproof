# Технические решения (ADR)

ADR фиксирует решение, которое влияет на архитектуру, внешние зависимости, данные, контракты или долгосрочную поддержку.

## Статусы

- `Proposed` — подготовлено к рассмотрению; не разрешает зависимую реализацию.
- `Accepted` — явно утверждено владельцем.
- `Rejected` — рассмотрено и отклонено.
- `Superseded` — заменено более поздним решением; укажи ссылку.

AI-агент может исследовать варианты и подготовить ADR. Статус `Accepted` и зависящие от него изменения утверждает владелец.
